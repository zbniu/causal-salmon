# Actual execution and reporting scope

The final reported batch is six user-labelled models × F01–F12 = 72 answers. All six models completed the same twelve cases: four answers in each world, comprising two numeric CSVs and two semantic versions per CSV. There are six distinct numeric datasets and 36 named/anonymous pairs.

The original plan was 18 cases per model. The owner abandoned F13–F18 **after reviewing the twelve-case results**. This was not a preregistered twelve-case scope. Those six cases are not pending, do not enter denominators and are not failures or UNKNOWN. The original eighteen-case materials remain available in the case index. See the [owner's decision record](scope_decision.md).

[planning.md](../planning.md) is the English reading translation of the frozen numerical design and original baseline. Original source bytes are retained in `manifests/frozen_protocol.md.gz`; translation hashes are registered separately. The actually used, owner-designated experiment prompt is [app_prompt.txt](../materials/app_prompt.txt), copied byte for byte from the prompt used in the reported sessions. The [artifact-based rubric](scoring.md) uses submitted report, code and outputs, without report-style grading or an EEE pass threshold. This simplified standard was adopted after initial formal submissions; grades were reconciled without retesting. Historical baseline report-extraction code is not the grader used for the reported batch.

The complete planned D01–D06 development matrix was not completed. Its data and upload materials are retained, while earlier prompt-feasibility checks, including D01, remain separate from the 72 formal answers.

The final evidence standard does not require original App traces. It was selected after initial formal submissions and supports PASS for eight GPT-5.6 Sol A/B answers that could not be fully verified under the trace requirement. Its four C decisions, submitted answers, adopted values and inputs were unchanged; no retest was conducted. All reported results use the same final standard. This disclosure describes evidence acceptance, not a model-performance improvement.

Scoring is nonblind assistant review of visible artifacts. Model labels follow owner records. Per-session model identity, actual prompt delivery and backend isolation were not independently verified. Original analysis code has not been rerun or repaired during packaging. Core PASS does not validate every supplementary calculation or prove general causal reasoning ability.

The root [README](../README.md) is the complete public research account, combining the project introduction and research report. It preserves the working-project report's research sections with links adapted to the public layout. Methods and outcomes include concise disclosure of post-results scope and evidence-standard decisions. Historical decisions remain in their records.
