# Tutoring class and score gain

**Answer.** For the 600 students who attended, the tutoring class increased the average score gain `z` by an estimated **1.26 points**. A 95% bootstrap confidence interval is **0.85 to 1.68 points**. This is the estimate that answers the research question: the average effect for the attendees, rather than the unadjusted difference between attendees and all nonattendees.

The attendees gained 13.02 points on average. I estimated that these same students would have gained 11.76 points on average without the class, after adjusting for their start-of-term score `y`. The raw difference against all nonattendees is 3.63 points, but attendees started much higher on average (67.07 versus 56.86), and gain also varies with the start score.

**Why the comparison can identify this effect.** All applicants whose start scores exceeded the lowest admitted start score were admitted, and all admitted students attended. Thus, over the attendees' start-score range, attendance reveals applicant status. Conditional on a given start score, the independent random part of the application score determines applicant status without using other student characteristics. Nonattendees with comparable start scores therefore provide a comparison for the attendees' untreated gains. This reasoning uses the study's description of the assignment process and does not require the undisclosed application scores or applicant list.

I used all 2,000 records. There are 600 attendees and 535 nonattendees within the attendees' observed score range (58.21–74.97). A cubic spline fit to these nonattendees' gains as a function of start score predicted the untreated gain at each attendee's score. The average observed gain minus those predictions is 1.25765 points. A stratified bootstrap with 2,000 resamples gave the interval above. Linear, quadratic, and alternative spline fits gave effects from 1.24 to 1.26 points; nearest-score matching gave 1.13 points. These checks support a positive average effect, though the exact effect depends somewhat on how the score adjustment is made.

The estimate concerns the **average effect for these attendees**. It does not establish each individual's effect or the effect of offering tutoring to students at lower start scores. The confidence interval reflects sampling and model estimation uncertainty under the stated assignment mechanism; the precise counterfactual mean is not directly observed.
