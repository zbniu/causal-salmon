# Original model submissions

Six user-labelled models completed F01–F12 each. [CASE_INDEX.csv](CASE_INDEX.csv) maps all 72 answers; [INDEX.csv](INDEX.csv) records the 915 original artifact members and hashes.

Each case contains its nonempty final report, all submitted analysis code and saved outputs, and run_log.txt when supplied. Case INDEX.md files are new navigation only. Original artifacts were copied byte for byte, including errors and unstable supplementary results. No submitted code was run, repaired or reconstructed. Cloud execution paths are preserved original evidence, not reproduction instructions.

The public evidence export includes the required report, code, saved results and execution records. Eight model-authored README files and 40 files under input-copy directories are not included in this export; those members remain in the original ZIP archives. Public upload materials supply the study descriptions and CSVs separately.

Case identifiers were reconstructed from available input content and recorded semantics, rather than trusted from download filenames. For four GPT-6.1 cases, exact input bytes could not be verified; their identification uses public statistical fingerprints and descriptions.

Original ZIP archives and full student-level hidden truth remain in the controlled project. These received materials support the current [artifact-based rubric](../../docs/scoring.md), without independently proving original session identity, prompt delivery, execution or context isolation.
