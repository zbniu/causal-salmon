# Public simulated data

[Selected development data](public/development/) contains three datasets. [Selected formal data](public/formal/) contains nine datasets. Each CSV has columns x,y,z, 2,000 rows and exactly 600 participants. Semantic descriptions change wording, never CSV values.

All 60 original public candidates and all four rejected cases are retained in the [qualification evidence](../results/qualification/README.md). The final 72 answers use six of the selected formal CSVs, specified in [case_index.csv](../configs/case_index.csv). Other selected datasets remain part of the original screened design but do not enter the final model-performance denominator.

Full student-level hidden records are excluded. Scalar SATT values in the research result table permit checking optional EEE. No real students or outcomes were collected.
